# 06 · Expense Tracker

API para registrar y consultar gastos.

## Endpoints

Base: `/api/Expenses` (controlador `ExpensesController`).

## Ejecutar

```bash
dotnet run --project practicas/backend/06-expense-tracker/ExpenseTracker
```

Swagger: `http://localhost:<puerto>/swagger`

## Notas

- No requiere base de datos: los datos viven en memoria.
- Ideal para probar el flujo completo con Swagger sin configuración adicional.
